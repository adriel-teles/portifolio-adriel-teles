## 📌 Sobre o Projeto

Este é o portfólio profissional de **Adriel Teles**, profissional da área de TI especializado em **suporte técnico, infraestrutura de redes, monitoramento de ambientes e Segurança da Informação**.

O objetivo principal deste projeto é apresentar suas competências técnicas, histórico acadêmico/profissional, projetos realizados (como observabilidade com Zabbix/Grafana/Wazuh, automação em Python e projetos web) e prover um canal direto de contato.

---

## 🎨 Conceito e Design

O design do site foi desenvolvido com inspiração visual em um **Dashboard de NOC (Network Operations Center) e Terminais Cyber**:
- **Cores**: Fundo escuro grafite/charcoal com acentos em verde terminal (`#35d07f`) para indicação de status/sucesso e âmbar/dourado (`#f2b84b`) para destaques.
- **Tema Claro / Escuro**: Suporte nativo a alternância de temas (Dark por padrão), mantendo a preferência do usuário salva no navegador (`localStorage`).
- **Tipografia**: Combinação de fontes Sans-Serif para leitura e Monospace para trechos de dados e competências técnicas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível (com atributos ARIA para leitores de tela).
- **CSS3 (Vanilla)**: Variáveis CSS (Custom Properties), layout responsivo (Flexbox e Grid), efeitos de transição e animações de foco.
- **JavaScript (ES6+)**: Lógica sem frameworks para manipulação do DOM, alternância de tema, controle do menu mobile e validação do formulário de contato.
